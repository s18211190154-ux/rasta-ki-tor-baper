# রাস্তা কি তোর বাপের? 😤

**Dhaka CNG Chaos Simulator™** — a satirical endless-runner inspired by the viral
Bangladeshi "Baper Rasta" (বাপের রাস্তা) meme: *"Is the road your father's?"*

Well, in this game — yes. It is. It's your father's road entirely.

**▶ Play live:** https://s18211190154-ux.github.io/rasta-ki-tor-baper/

## The joke

You are a CNG auto-rickshaw driver in Dhaka. There are no rules; there is only
**vibes and horn**. Inspired by the viral trend, but an original game: original
code, original art (emoji, the finest art form), original insults.

## Gameplay

- 🛺 **Drive** — ⬅️➡️ / A D to weave lanes (on phone: tap left/right, center = honk)
- 📢 **HONK (SPACE)** — the sacred art. Traffic ahead literally flees in fear. This is culturally accurate.
- 🪙 **Collect baper taka** — you don't earn; you collect
- 🐄 **Dodge cows** — the cow was there first, legally
- 🕳️ **Potholes** — not deadly, just spiritually damaging ("ধক!")
- 👻 **Near-misses** — the closer you pass, the more Bangla commentary the game shouts at you
- 💀 **Crash** — every game over is a random autopsy: *"মামা, বাসটা দেখি নাই 👀"*
- 🏁 Milestones, speed streaks, screen shake, confetti-free tragedy, best score saved locally

Everything is bilingual (Bangla + English) so your non-Bangladeshi friends can
also be confused.

## Tech

Zero dependencies. One HTML file + one CSS file + one JS file. Canvas rendering,
Web Audio API for the horn (a synthesized three-tone air horn), synthesized crash sounds.
~700 lines of carefully curated chaos.
